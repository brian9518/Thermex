# thermex.uz

Сайт официального партнёра Thermex в Узбекистане (ООО «SAN-NEO»). Статический сайт,
публикуется через GitHub Pages с ветки `root` на домен из файла `CNAME` (www.thermex.uz).

## Как устроен

| Что | Где |
|---|---|
| Генератор страниц (единственный источник правды) | `tools/build.py` |
| Характеристики и фото моделей с thermex.ru | `tools/data/thermex.json` |
| 6 моделей с собственными фото и характеристиками | `tools/data/featured.json` |
| Стили и скрипты сайта | `assets/css/site.css`, `assets/js/site.js` |
| Данные моделей для окна «Подробнее» (генерируется) | `assets/js/catalog-data.js` |
| Картинки (WebP) и фото моделей | `assets/img/`, `assets/img/p/` |
| PDF-каталог | `files/` |
| Пересылка заявок в Telegram-группу (не подключена) | `telegram-worker/` |

HTML-страницы, `sitemap.xml` и `robots.txt` **генерируются** — в начале каждой страницы
есть комментарий об этом. Править нужно генератор, а не HTML: иначе правка пропадёт
при следующей сборке.

## Как внести изменение

1. Откройте `tools/build.py`. Контакты, адрес, режим работы — константы в начале файла;
   список моделей — `CATALOG`; тексты страниц — функции `home()`, `catalog()` и т. д.
2. Соберите сайт (нужен только Python 3.8+, без зависимостей):

   ```bash
   python3 tools/build.py
   ```

3. Закоммитьте изменённые файлы вместе с перегенерированными HTML/JS и откройте PR в `root`.

Добавить модель: строка в `CATALOG`. Если у модели есть страница на thermex.ru, её фото и
характеристики можно добавить в `tools/data/thermex.json` (структуру видно по соседним
записям), а фото положить в `assets/img/p/<id>-1.webp`.

## Что не хранится в репозитории

- Цены (прайс оптовый) — на сайте их нет и быть не должно.
- Токен Telegram-бота — только в секретах Cloudflare, см. `telegram-worker/README.md`.
- Исходники картинок в полном размере — в репозитории только оптимизированные WebP.
