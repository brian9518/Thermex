# Заявки с сайта → Telegram-группа

Формы на сайте отправляют заявку на небольшой сервер-посредник (Cloudflare Worker),
а он публикует её в вашей Telegram-группе или канале. Токен бота хранится только
в Cloudflare и не виден посетителям сайта.

Пока посредник не подключён, кнопка «Отправить заявку» открывает WhatsApp —
сайт работает и без него.

Настройка занимает около 10 минут и бесплатна.

## 1. Создайте бота

1. В Telegram откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot`.
2. Придумайте имя (например, `Thermex заявки`) и username (например, `thermex_leads_bot`).
3. BotFather пришлёт **токен** вида `1234567890:AAH...`. Никому его не показывайте.

## 2. Добавьте бота в группу или канал

- **Группа:** создайте группу (например, «Заявки Thermex»), добавьте туда бота и сотрудников.
- **Канал:** добавьте бота в канал как **администратора** с правом публикации сообщений.

## 3. Узнайте ID группы (chat_id)

1. Напишите в группе `/start@ИМЯ_ВАШЕГО_БОТА` (в канале — просто опубликуйте любой пост).
2. Откройте в браузере, подставив свой токен:
   `https://api.telegram.org/botТОКЕН/getUpdates`
3. Найдите `"chat":{"id":-100...` — это число (вместе с минусом) и есть **chat_id**.

Если ответ пустой (`"result":[]`), отправьте сообщение ещё раз и обновите страницу.

## 4. Разверните посредника в Cloudflare

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) (бесплатный тариф).
2. **Workers & Pages → Create → Create Worker**, назовите `thermex-leads`, нажмите **Deploy**.
3. Нажмите **Edit code**, удалите всё и вставьте содержимое файла `worker.js` из этой папки.
   Нажмите **Deploy**.
4. Откройте **Settings → Variables and Secrets** и добавьте:

   | Имя | Тип | Значение |
   |---|---|---|
   | `TELEGRAM_BOT_TOKEN` | Secret | токен из шага 1 |
   | `TELEGRAM_CHAT_ID` | Text | chat_id из шага 3 |

5. Скопируйте адрес воркера — он вида `https://thermex-leads.ВАШ-АККАУНТ.workers.dev`.

## 5. Подключите к сайту

В файле `assets/js/site.js` впишите адрес воркера:

```js
var LEAD_ENDPOINT = 'https://thermex-leads.ВАШ-АККАУНТ.workers.dev';
```

Или просто пришлите адрес Claude — он внесёт изменение сам.

## Проверка

Отправьте заявку на сайте — через секунду она появится в группе:

```
🔔 Новая заявка с сайта

Имя: Иван
Телефон: +998 90 123 45 67
Тема: Установка

Страница: Контакты — /Контакты.html
```

## Защита от спама

- Принимаются только запросы с `thermex.uz` и `www.thermex.uz`
  (чтобы добавить другой домен, создайте переменную `ALLOWED_ORIGINS`
  со списком адресов через запятую).
- Скрытое поле-ловушка отсеивает ботов.
- Длина полей ограничена, HTML экранируется.
